# The Open Markdown Bookmark Format

A vendor-neutral, plain-markdown bookmark format — originated by
[mardo](https://github.com/hbroek/mardo) — with a free-form extension
mechanism for tool-specific data (ratings, visit history, whatever a given
tool needs).

**Read the spec**: [open-markdown-bookmark-format.henryvandenbroek.com](https://open-markdown-bookmark-format.henryvandenbroek.com)
(or [docs/index.md](docs/index.md) to read it here on GitHub).

## Implementations

- [mardo](https://github.com/hbroek/mardo) — the format's origin.
- [LinkaGoGo](https://www.linkagogo.com) — core format plus its own extension
  (ratings, favorites, visit history, reminders, aliases, smart URLs, RSS).
  See the spec's §4.1 and LinkaGoGo's
  [format page](https://www.linkagogo.com/bookmarks-markdown.md).

Using this format in your own tool? Open a pull request adding it to this
list.
